terminal 2-Minute Deployment StepsStep-by-Step
  1. Create a new GitHub repository named aeropulse-sg.
  2. Save this code as index.html and git push.
  3. Go to vercel.com → Click "Add New Project" → Import your repo.
  4. Framework Preset: Other (or Root Directory: ./).
  5. Hit Deploy! Live globally in 30 seconds with automatic HTTPS & edge caching.
